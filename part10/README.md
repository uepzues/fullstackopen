# Full Stack Open - Part 10: React Native

This repository contains my solutions and project work for **Part 10** of the University of Helsinki's [Full Stack Open](https://fullstackopen.com/) course.

## Overview
Part 10 focuses on extending web development concepts with React to cross-platform native mobile application development using **React Native** and **Expo**.

## Key Concepts & Skills
* **Mobile UIs & Styling:** Building native components, applying styling with `StyleSheet`, and handling mobile layout and touch events.
* **Navigation:** Implementing seamless multi-screen navigation using React Navigation.
* **State & Data Fetching:** Connecting the mobile application to a GraphQL backend using **Apollo Client** for queries, mutations, and caching.
* **Form & Input Handling:** Managing user input and form validation in a mobile context.
* **Testing & Deployment:** Writing unit and integration tests for React Native components and preparing the app for release.
